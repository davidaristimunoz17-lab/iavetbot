Capacidades del Agente

Módulos Clínicos de Alta Precisión

Diseñado para estudiantes y médicos veterinarios en formación, eliminando la intuición subjetiva y automatizando cálculos críticos.

🚨

Triaje Clínico Cuantitativo

Reemplaza la intuición empírica por un sistema estricto de 5 preguntas clínicas obligatorias (0 a 15 puntos). Clasifica al paciente en Código Verde, Amarillo o Rojo con tiempos de atención definidos y alerta prioritaria ante signos de shock.

  • Parámetros: Estado mental, mucosas/TLC, hidratación, respiración y pulso.
  • Alerta prioritaria si pulso ausente, disnea grave o coma.
  • Escala matemática libre de sesgos diagnósticos.
💊

Dosificación Farmacológica Ultra-Concisa

Cálculo matemático directo estructurado estrictamente en 3 pasos limpios en texto plano: Fórmula, Operación y Resultado. Elimina textos innecesarios y aplica la regla de proporcionalidad dimensional de mg/kg.

  • Soporte para líquidos (% y mg/ml) y tabletas sólidas.
  • Protección contra la división errónea de dosis entre peso.
  • Evaluación aritmética segura en Python con módulo ast.
💧

Plan de Fluidoterapia Integral

Calcula en segundos el déficit de deshidratación, volumen de mantenimiento diario (50 ml/kg/día), volumen total de reposición en 24 horas y velocidad de infusión en ml/h y gotas por minuto con normogotero.

  • Guía explicativa de deshidratación integrada (5% a 12%).
  • Cálculo con pesos reales fisiológicos de 0.05 a 250 kg.
  • Gotas por minuto para bombas de infusión o goteros manuales.
☀️

Riesgo Térmico & Protocolos Locales

Evalúa el riesgo de golpe de calor en tiempo real consultando la temperatura y humedad meteorológica por ciudad (Open-Meteo), con alertas especiales para razas braquicéfalas y consulta de protocolos clínicos locales.

  • Grounding con protocolos_vet/ para evitar alucinaciones.
  • Índice de calor y recomendaciones de enfriamiento seguro.
  • Alerta crítica para bulldogs, pugs y gatos persas.

Guía Clínica de Estimación de Deshidratación en Pacientes

El bot explica al usuario en qué consiste cada porcentaje para ingresar el valor exacto en el cálculo de fluidoterapia:

📚 Fuente: Protocolos de Fluidoterapia Veterinaria
< 5%
Subclínica
No detectable en examen físico. Se sospecha por historia clínica de pérdidas (vómitos leves, diarrea inicial o privación de agua).
5% - 6%
Leve
Mucosas orales ligeramente secas o pegajosas. Pliegue cutáneo dorsal recupera elasticidad en 1 a 2 segundos. Ojos normales.
7% - 8%
Moderada
Mucosas francamente secas, pliegue cutáneo tarda de 2 a 3 segundos en regresar. Hundimiento ocular leve (enoftalmos), tiempo de llenado capilar de 2s.
9% - 10%
Severa
Pliegue cutáneo persistente (más de 3 segundos), mucosas muy secas y pálidas, globos oculares notablemente hundidos, extremidades frías y pulso débil.
11% - 12%+
Crítica / Shock
Signos francos de shock hipovolémico: colapso, estupor o coma, pulso casi imperceptible, llenado capilar > 3s, riesgo inminente de paro cardiovascular.

Justificación en la Práctica y Educación Veterinaria

Por qué la integración de agentes de inteligencia artificial deterministas y seguros transforma la formación y el ejercicio clínico.

01

Estandarización del Triaje

Elimina la subjetividad del personal en triage de urgencias. El sistema de puntuación cuantitativa (0 a 15) asegura que cada paciente reciba el color de código exacto basado en signos vitales medibles.

02

Cero Margen de Error en Dosis

Los errores de dosificación son la primera causa de iatrogenia farmacológica en medicina de pequeños animales. El agente impone el cálculo dimensional estricto y valida rangos fisiológicos.

03

Agilidad en Tiempos Críticos

En salas de urgencias, calcular fluidoterapia o verificar compatibilidad terapéutica toma segundos a través de Telegram, permitiendo enfocar la atención humana en maniobras de reanimación.

04

Herramienta Docente Segura

Incorpora filtros éticos contra prescripción indiscriminada, anonimización automática de datos de tutores y aviso obligatorio de supervisión profesional en cada respuesta.

# Agente IA de Triaje y Apoyo Clínico Veterinario

Asistente académico para estudiantes de Medicina Veterinaria: clasifica urgencias, calcula dosis y fluidoterapia con funciones exactas de Python y consulta protocolos locales. No sustituye a un Médico Veterinario titulado.

## 1. Requisitos

- Python 3.10 o superior.
- Opcional: Ollama con el modelo llama3.2:3b para usar IA local.
- Opcional: token de Telegram y un ID de usuario autorizado.

## 2. Instalación

En la carpeta del proyecto:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

En Linux/macOS:
`python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && cp .env.example .env`

## 3. Elegir el cerebro

Edita .env y define CEREBRO:

| Valor | Descripción |
| --- | --- |
| ollama (por defecto) | Modelo local llama3.2:3b en http://localhost:11434. Instala Ollama y ejecuta ollama pull llama3.2:3b antes de arrancar. |
| api | Endpoint compatible con OpenAI/Groq: configura API_BASE, API_KEY y API_MODEL. |
| reglas | Modo sin IA: decisiones deterministas y herramientas reales. Útil para clase, pruebas o cuando no hay modelo disponible. |

Si Ollama o la API fallan, el agente responde automáticamente con el modo reglas.

## 4. Ejecutar en consola

```powershell
python main.py --canal consola
```

También es el valor por defecto: python main.py.

Ejemplos:
- Clasifica el triaje de un gato con disnea grave
- Calcula la dosis de 10 mg/kg para un perro de 12 kg
- Fluidoterapia para un perro de 10 kg con 6% de deshidratación
- ¿Cuál es el riesgo de golpe de calor en Medellín para un bulldog?
- /reset
- /salir

Límites activos: 10 mensajes por minuto y 1500 caracteres por mensaje. /reset borra los últimos mensajes guardados para ese chat.

## 5. Ejecutar en Telegram

1. Crea un bot con BotFather y copia el token a TELEGRAM_TOKEN en .env.
2. Obtén tu ID numérico de usuario y ponlo en TELEGRAM_ADMINS (varios IDs separados por comas).
3. Arranca:

```powershell
python main.py --canal telegram
```

El adaptador usa long polling con requests.

## 6. Pruebas automatizadas

```powershell
python tests/evaluar.py
```

Ejecuta 6 casos clínicos (dosis, fluidoterapia, triaje, riesgo térmico con clima simulado, peso negativo e inyección de prompt) usando CEREBRO=reglas. Imprime aciertos, tasa de éxito y latencia media.

## 7. Estructura

- main.py: Entrada, canales y rate limit
- agente.py: Prompt sistema, ReAct (4 pasos), JSON estricto y 1 reintento
- cerebro.py: ollama | api | reglas
- herramientas.py: Dosis (ast), fluidoterapia, protocolos y Open-Meteo
- flujo_guiado.py: Máquina de estados conversacional, triaje 5 parámetros y ficha
- memoria.py: SQLite: últimos 6 mensajes por chat y /reset
- canal_telegram.py: Long polling + menús y teclados interactivos
- protocolos_vet/: Única fuente de verdad clínica (grounding)
- tests/evaluar.py: Evaluación con 6 casos
- datos/agente.sqlite3: Base de datos local (se crea automáticamente)

## 8. Seguridad y ética

- Los cálculos se ejecutan con ast, nunca con eval().
- El triaje solo se responde con fragmentos de protocolos_vet/.
- Si falta el peso u otro dato indispensable, el agente lo pide antes de operar.
- Se ignoran instrucciones para saltarse reglas, desactivar el aviso o emitir recetas médicas.
- La memoria anonimiza correos, teléfonos e identificadores obvios; usa únicamente casos ficticios.
- Toda respuesta clínica lleva el aviso de apoyo académico y no sustitución profesional.
